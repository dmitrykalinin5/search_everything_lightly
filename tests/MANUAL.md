# Ручная проверка GNOME Shell 49 / Wayland

Автоматические тесты поиска не заменяют проверку GNOME Shell. Перед публикацией заполните этот список на реальном рабочем столе.

- [ ] Чистая установка через `make install`, выход/вход, `make enable`; нет ошибок в Extensions.
- [ ] Super+Space открывает окно; Escape закрывает; повторное открытие очищает текст и фокусирует ввод.
- [ ] Если сочетание занято раскладкой: изменить в `make prefs`, проверить новое, сбросить.
- [ ] 10 быстрых открытий/закрытий, отключение во время поиска и повторное включение: нет зависаний/ошибок journal.
- [ ] Латиница, кириллица, пробелы, emoji, кавычки, `*`, `?`, `[abc]`, `[a-z]`, `[!abc]`, экранированные спецсимволы и обратная косая черта.
- [ ] `re:` поддерживает POSIX ERE, показывает ошибку для неверного выражения и не блокирует интерфейс на сложном запросе.
- [ ] Один символ запускает поиск приложений и файлов; пустая строка не запускает; длинная вставка ограничена.
- [ ] `*.js`, `?.js`, `one*.js` сопоставляются с именем файла; `\*`, `\?` ищут буквальные символы.
- [ ] Приложения показаны плитками над файлами; ←/→ выбирают плитки, ↑/↓ переходят между рядами и файлами.
- [ ] Приложение запускается кликом и Enter, в том числе при недоступном plocate.
- [ ] Рабочий стол не затемняется; окно компактное, полупрозрачное и тёмное; подсказки клавиш внизу нет.
- [ ] При открытии видна только строка поиска с плавным `fade + scale`; первый символ раскрывает панель результатов.
- [ ] После раскрытия удаление всего запроса не сжимает окно; новое открытие снова начинается с компактной строки.
- [ ] При длинном списке виден ползунок, его размер и положение отражают доступную прокрутку.
- [ ] После первого символа размер и положение окна постоянны при вводе и стирании запроса, загрузке, пустых результатах и ошибках; длинный список прокручивается внутри окна.
- [ ] При добавлении символов старые результаты не исчезают во время debounce и поиска; готовый новый список появляется одним обновлением.
- [ ] 100+ совпадений: показаны максимум 50, нижние строки доступны стрелками и прокруткой.
- [ ] Точное имя выше совпадения в пути; при одинаковом качестве HOME выше системных путей.
- [ ] ↑/↓, Tab, Ctrl+L, Ctrl+A, Enter и щелчок; выбранная строка хорошо видна.
- [ ] Enter открывает файл и папку; Ctrl+Enter — родителя; Shift+Enter — выделение в Files.
- [ ] Удалить найденный файл перед Enter: понятная ошибка, окно остаётся открытым.
- [ ] Новый обычный файл находится через LocalSearch без `sudo updatedb`; поиск работает при удалённом или недоступном `plocate`.
- [ ] С установленным plocate находятся разрешённые скрытые и системные файлы; маски и регулярные выражения дают понятную инструкцию без plocate.
- [ ] Недоступный диск и недоступные индексы обрабатываются без зависания.
- [ ] Окно настроек: запись и сброс сочетания, закрытие клавишей Escape, перевод, состояние источников и пояснение про необязательный `sudo updatedb`.
- [ ] Светлая/тёмная тема, 100%, дробный масштаб, 200%: строки/подсказки не обрезаны.
- [ ] Два монитора: фокус на втором при указателе на первом, окно появляется на втором.
- [ ] Отключение монитора при открытом поиске безопасно закрывает окно.
- [ ] Блокировка сеанса при открытом поиске: overlay убран, после разблокировки расширение работает.
- [ ] Чистая установка архива `dist/*.shell-extension.zip` и отсутствие тестовых файлов в нём.

Для скриншотов используйте только специально подготовленные тестовые файлы без личных путей.
